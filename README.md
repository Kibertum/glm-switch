# GLM Switch

Небольшое приложение для Windows, которое переключает официальное расширение
Claude Code for VS Code между Claude и GLM через настройки Claude Code.

## Возможности

- Переключение между Claude и совместимым с Anthropic API Z.AI.
- Именованные профили API-ключей: сохранение, выбор и удаление.
- Сохранённые профили шифруются Windows DPAPI и доступны только текущей учётной
  записи Windows.
- При возврате на Claude восстанавливаются прежние значения управляемых
  переменных; остальные настройки Claude Code сохраняются.
- Перед первым переключением создаётся копия `settings.json`.

## Использование

1. Запустите `GLM Switch.exe`.
2. Для нового ключа укажите имя и ключ, затем нажмите **Сохранить ключ**.
   Новый ключ также можно ввести и сразу включить GLM.
3. Для уже сохранённого ключа выберите профиль в списке и нажмите
   **Переключить на GLM**. Чтобы убрать профиль, выберите его и нажмите
   **Удалить выбранный**.
4. Нажмите **Вернуть Claude**, чтобы восстановить настройки Claude.
5. После переключения перезапустите текущий чат Claude Code.

Пока GLM включён, активный ключ находится в
`%USERPROFILE%\.claude\settings.json` в открытом виде: расширению Claude Code
нужно прочитать его при запуске. Нажатие **Вернуть Claude** удаляет этот
переопределённый ключ, но оставляет зашифрованный профиль для следующего раза.
Не публикуйте `settings.json` и резервные копии этого файла.

Настройки GLM: `https://api.z.ai/api/anthropic`, модели
`glm-5.3[1m]` и `glm-5.3-flash[1m]`. Идентификаторы моделей соответствуют
настройке переключателя из исходного рабочего примера и могут зависеть от
доступности в плане Z.AI.

## Где получить ключ

Откройте [список API-ключей Z.AI](https://z.ai/manage-apikey/apikey-list) и
перейдите на вкладку **Personal Coding Plan**. Создайте ключ там и сохраните
его в приложении под отдельным именем.

Не используйте ключи со вкладки **Standard**: Z.AI управляет ими отдельно,
и они предназначены только для Standard Model API. Для этого приложения нужен
именно ключ Personal Coding Plan.

## Требования

- Windows x64.
- .NET 8 Desktop Runtime.
- Claude Code for VS Code и `%USERPROFILE%\.claude\settings.json`.
- API-ключ Z.AI с доступом к совместимому с Anthropic API.

## Сборка и проверка

Из корня проекта:

```powershell
dotnet publish .\GLMSwitchApp.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o .\publish
.\publish\GLM Switch.exe --self-test
```

Для разработки нужен .NET 8 SDK и Windows Desktop Runtime. Самопроверка
использует временные тестовые файлы и не изменяет настройки Claude Code.
